# Paper lanterns

Chōchin (提灯) are collapsible paper lanterns on a spiral bamboo frame: the frame folds flat, the paper stays attached. This note is **not published**, so Niwa shows links to it as plain text while Kura links it.

> [!note] Search
> Kura's full-text search finds this note for "bamboo" and for "chochin".

## Parts

| Part | Made of | Notes |
|---|---|---|
| Frame | split bamboo ribs ([[Bamboo frames]]) | one continuous spiral for the folding kind |
| Skin | [[Washi paper]] | kozo fibre, 25-30 g/m² |
| Caps | cedar or card | top and bottom rings |
| Light | candle or LED | see [[Candle vs LED]] |
