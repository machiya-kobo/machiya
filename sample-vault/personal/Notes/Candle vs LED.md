# Candle vs LED

| | Candle | LED |
|---|---|---|
| Colour | warm, flickers | steady, tunable |
| Heat | scorches paper after a while | none |
| Runtime | 2 hours | weeks |

Plan: use an LED insert for display and keep candles for the festival night. Tracked in [[LED insert]].
