# The organization's own repositories

Files for two repositories that exist only to present the `machiya-kobo` organization. Both repositories exist (private, created 2026-10-07) and hold these files; at launch make them public, and for `machiya-kobo.github.io` turn on Pages (Settings -> Pages -> Source: GitHub Actions) and run its `pages` workflow. Change a file here first, then copy it there.

| Folder | Repository | What it does |
|---|---|---|
| [`.github/`](.github/) | `machiya-kobo/.github` | `profile/README.md` is the page github.com/machiya-kobo shows |
| [`machiya-kobo.github.io/`](machiya-kobo.github.io/) | `machiya-kobo/machiya-kobo.github.io` | publishes this repository's `site/` at https://machiya-kobo.github.io/ (Settings -> Pages -> Source: GitHub Actions) |

The page itself stays in [`site/`](../site/); nothing here duplicates it.
